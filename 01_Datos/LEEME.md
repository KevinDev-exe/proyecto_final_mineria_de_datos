# 01_Datos

Dataset **Credit Card Fraud Detection** — Kaggle: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

- `creditcard.zip` (68,5 MB): contiene `creditcard.csv` (284.807 transacciones, 31 columnas, 492 fraudes).
- El CSV descomprimido pesa 150 MB y GitHub no acepta archivos de más de 100 MB, por eso en el repositorio solo está el `.zip`.

**No es necesario descomprimirlo:** el notebook lee el `.zip` directamente si no encuentra `creditcard.csv`.
Si se prefiere, se puede descomprimir aquí mismo para obtener `01_Datos/creditcard.csv`.
